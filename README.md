# Product Catalog Web App (Django): BNEX Challenge

A small Django web application built for a hiring challenge: a product catalog with a
`Produto` model (name, description, price, created and modified timestamps), Django admin
integration and HTML templates.

## Run it

```bash
pip install django
python manage.py migrate
python manage.py runserver
# http://127.0.0.1:8000
```

## Stack

Python, Django, SQLite.
